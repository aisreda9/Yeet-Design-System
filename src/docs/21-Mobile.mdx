# iOS и Android

Приложение нативное. Storybook — **эталонная реализация и спецификация**: каждый компонент здесь показывает поведение,
размеры, состояния и контексты. Нативные компоненты повторяют его API и берут значения из общих токенов.

## Один источник токенов

```
tokens/tokens.json          ← правим только здесь (или синхронизируем из Figma «Yeet DS 2.0»)
        │  npm run tokens
        ├── src/tokens/tokens.generated.css     web / Storybook
        ├── tokens/ios/YeetTokens.swift          SwiftUI (только токены)
        ├── native/ios                           SwiftUI-компоненты: Swift Package YeetDesignSystem
        └── tokens/android/YeetTokens.kt         Jetpack Compose
```

Что внутри: семантические цвета со светлой и тёмной темой, цвета вещей, шкала отступов, радиусы, 5 текстовых стилей,
тень `floating`, анимации. Сгенерированные файлы руками не правятся.

## iOS · SwiftUI

Компоненты — Swift Package `YeetDesignSystem` в `native/ios` (iOS 16+): `YeetButton(variant: .primary, size: .l)`, `YeetSheet`,
`YeetHeader(type: .large(...))` и т. д., подключение через SPM по URL репозитория, шрифты внутри пакета.
Таблица соответствий React ↔ Swift — `native/ios/README.md`.

Только токены: скопируйте `YeetTokens.swift` в проект и добавьте шрифты Roboto Slab и Inter в приложение.

```swift
Text("Гардероб")
  .yeetText(YeetType.h1)
  .foregroundStyle(YeetColor.textPrimary)

RoundedRectangle(cornerRadius: YeetRadius.lg)
  .fill(YeetColor.bgSubtle)          // тёмная тема — автоматически

stamp.scaleEffect(isDone ? 0.53 : 1)
  .rotationEffect(.degrees(isDone ? -60 : 0))
  .animation(YeetMotion.stamp, value: isDone)   // та же пружина, что в Figma (Bouncy)
```

## Android · Jetpack Compose

Скопируйте `YeetTokens.kt` в модуль (`package design.yeet.tokens`), шрифты — в `res/font`.

```kotlin
val colors = if (isSystemInDarkTheme()) YeetDarkColors else YeetLightColors
val type = YeetTypography.fromResources(R.font.roboto_slab_variable, R.font.inter_variable)

Text("Гардероб", style = type.h1, color = colors.textPrimary)

val scale by animateFloatAsState(if (done) 0.53f else 1f, animationSpec = YeetMotion.stamp())
```

## Анимации на платформах

Пружины Figma (Gentle, Quick, Bouncy) заданы физикой: масса, жёсткость, демпфирование. SwiftUI (`interpolatingSpring`)
и Compose (`spring(dampingRatio, stiffness)`) используют ту же модель, поэтому движение совпадает с прототипом один в один.
В web эти же пружины переведены в CSS `linear()`.

## Правила для нативных компонентов

1. **Имена свойств — как в Figma и в Storybook.** `ChatBubble(from: .user)`, `WeatherCard(temperature:description:icon:)`,
   `Button(variant: .primary, size: .l)`. Таблица соответствий — «Процессы / Figma ↔ код».
2. **Слоты — через content-замыкания.** Sheet, Dialog, InputGroup, ListGroup, Carousel принимают `@ViewBuilder content`
   (SwiftUI) или `content: @Composable () -> Unit` (Compose).
3. **Цвета — только семантические** (`YeetColor.bgSubtle`), никогда примитивы или hex.
4. **Размеры экрана.** Макеты — iPhone 393×852, поля 20. На Android те же значения в dp.
5. **Системные элементы** (статус-бар, клавиатура, «хоум»-индикатор) — нативные, в дизайн-системе только для макетов.
6. **Уменьшение движения.** iOS «Reduce Motion» и Android «Remove animations» — переходы мгновенные.
7. **Тап-зона — минимум 44 pt (iOS) / 48 dp (Android).** Визуально кнопка может быть 40, недостающее — невидимый hit-slop,
   раскладка не меняется (см. ниже). `YeetButton` / `YeetIconButton` в `native/ios` уже делают это сами.

## Тап-зона

```swift
// Иконка-кнопка 40 × 40, нажимается в 44 × 44
Button(action: close) {
  Image(systemName: "xmark").frame(width: 40, height: 40)
}
.yeetHitArea(height: 40)   // = .contentShape(Rectangle().inset(by: -2)): вид и раскладка не меняются

// Когда место позволяет — рамка вместо выхода за края
Button(action: close) {
  Image(systemName: "xmark")
    .frame(minWidth: 44, minHeight: 44)
    .contentShape(Rectangle())
}
```

```kotlin
// Видимая кнопка 40 dp, зона нажатия 48 dp
Box(
  Modifier
    .minimumInteractiveComponentSize()   // Material 3: добирает до 48 dp, видимый размер не меняется
    .size(40.dp)
    .clip(CircleShape)
    .clickable(onClick = onClose),
)
```

Зоны соседних кнопок не должны перекрываться: если 44 / 48 не помещаются — раздвинуть кнопки, а не уменьшать зону.
