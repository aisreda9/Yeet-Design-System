# yeet · Design System

**YeetStyle** — умный гардероб: пользователь оцифровывает свои вещи, получает образы на каждый день под погоду и повод,
ищет похожие вещи по фото и общается с ИИ-стилистом.

Дизайн-система — единый язык для дизайна и разработки: **токены, компоненты и правила**, из которых собираются все экраны
приложения. Одно и то же живёт в трёх местах:

| Где | Что | Для кого |
|---|---|---|
| **Figma** · страница «Design System 2.0 (Claude)» | Компоненты и все их варианты из флоу | Дизайн |
| **Storybook** (вы здесь) | Живые компоненты, правила, примеры экранов | Продукт, разработка, дизайн |
| **DESIGN.md** в репозитории | Указатель: что где лежит, ID страниц Figma, таблицы токенов (генерируются) | Разработка, ревью |

## Что это даёт

- **Скорость.** Новый экран собирается из готовых блоков, а не рисуется и верстается с нуля.
- **Консистентность.** Одна кнопка «Удалить» везде красная, одна шапка ведёт себя одинаково при скролле.
- **Тёмная тема бесплатно.** Компоненты используют семантические токены — тема меняет только значения.
- **Один язык.** Имена в Figma и в коде совпадают: `button / Primary / L` ↔ `<Button variant="primary" size="L" />`.

## Как читать Storybook

1. **Старт** — быстрый старт для разработчиков, принципы и устройство системы.
2. **Foundations** — токены, типографика, отступы, иконки, правила скролла и текстов.
3. **Atoms → Molecules → Organisms → Templates → Pages** — компоненты по уровням; **Прототип** — те же экраны в одном кликабельном приложении. У каждого: интерактивная песочница,
   все варианты и раздел **«В флоу»** — где именно в приложении он используется.
4. Переключатель **темы** — в верхней панели.
