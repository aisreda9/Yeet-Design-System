# Figma ↔ код

**Figma:** файл YeetStyle 2.0 → одна страница **Design System 0.2** (компоненты и экраны), коллекция переменных **Yeet DS 2.0** (Light / Dark).
Секции слева направо — как сайдбар Storybook: Старт · Foundations (с «Анимациями») · Atoms · Molecules · Organisms · Templates · Pages. Группа компонента подписана путём истории (`Molecules/ChipGroup`),
внутри уровня — по алфавиту. В секциях компонентов — только компонент со всеми вариантами; пример использования — экраны в Pages.

**Навигация в обе стороны.** Figma → Storybook: подпись группы и строка «Уровень · Код · Storybook» в описании компонента.
Storybook → Figma: кнопка **Figma ↗** в тулбаре — компонент ведёт на свой узел (`figmaId` в реестре), экран Pages — на кадр в «Pages/Экраны флоу · Light»,
документация — на секцию уровня. Узлы берутся из снимка `src/docs/figma-nodes.json`; `npm run qa` (coverage) падает, если `figmaId` из реестра в снимке нет.

## Свойства компонентов

Правило: **свойство Figma = пропс кода = параметр в iOS / Android**. Имена совпадают по смыслу, варианты — по значениям в нижнем регистре.

| Figma | Код |
|---|---|
| `button` · Style=Primary, Size=L, Left Icon | `<Button variant="primary" size="L" leftIcon="plus">` |
| `icon-button` · Style=Tertiary, Icon=more | `<IconButton variant="tertiary" icon="more" label="Ещё" />` |
| `stamp` · Tone, State=Done, Label, Icon | `<Stamp variant="primary" done label="Надеть" />` |
| `badge` · Style=Danger, Label | `<Badge variant="danger">-10%</Badge>` |
| `input-group` (слот Inputs) + `input` | `<InputGroup><Field label value trailingIcon /></InputGroup>` |
| `segment-control` · Size=L, Content=Icon | `<SegmentControl size="L" segments={[{ value, icon }]} />` |
| `list-group` (слот Rows) + `list-group / row` · Label, Trailing | `<ListGroup><ListItem label trailing /></ListGroup>` |
| `header` · Type=Bar, title-chip | `<Header type="bar" titleChip="Новая вещь" />` |
| `bottom-nav` · FAB=true | `<BottomNav active="wardrobe" fab />` |
| `sheet` · Footer=Buttons, Type=Panel (слот Content) | `<Sheet type="panel" footer={[…]}>…</Sheet>` |
| `dialog` · Tone=Destructive | `<Dialog variant="destructive" …>` |
| `product-card` · Name, Price, Discount, Show Like | `<ProductCard name price discount liked />` |
| `chat-bubble` · From=User, Text | `<ChatBubble from="user">…</ChatBubble>` |
| `weather-card` · Temperature, Description, Icon | `<WeatherCard temperature="20°" description icon="sun" />` |
| `trip-card` · Type=Add / Trip, City, Meta | `<TripCard add />` / `<TripCard city items outfits />` |
| `carousel` · Title (слот Cards) | `<Carousel title>…</Carousel>` |
| `bar-chart` из `bar-chart / bar` · Value, Icon | `<BarChart bars={[{ value, icon }]} />` |
| `outfit-collage` (слот Items) | `<OutfitCollage items={[{ kind, x, y, src }]} />` |

**Слоты.** Там, где содержимое меняется от экрана к экрану, в Figma слот, а в коде `children`: input-group, list-group, segment-control, chip-group, sheet, dialog, carousel, outfit-collage. Внутрь слота кладутся инстансы компонентов — их свойства настраиваются прямо в панели справа, без detach.

## Расхождения в Figma

Исправлено на странице Design System 0.2 (до 29.09 — «Design System 2.0 (Claude)») и в коллекции «Yeet DS 2.0» (оригинал не тронут): пустая тёмная тема,
опечатки (`ui-colors/balck`, `…-inner-sate`, «Поиска по странам», подпись свотча Red), мусорные переменные, путаница `chevron-up` / `chevron-up-down`,
«сырые» фреймы в организмах, хардкод `#F1F4FF` у чипсов, радио из спрятанной иконки, шевроны из стороннего кита, токен `on-accent` для текста на синем и красном.

Открыто:
- 4 фона коллажей с точечным паттерном («Photo & Image Areas», карточки) привязаны к `light-grey` исходной коллекции — PATTERN-заливку нельзя перепривязать через API, только вручную.
- Скругление последней карточки в сетке Гардероба — 32 вместо 20 (экран флоу).
- Экраны флоу New app design собраны из «сырых» фреймов на исходной коллекции — переводятся на компоненты 2.0 по одному.
- Тексты с родом в проде («Забыла пароль?», «Увидела в соцсетях…») — заменить по «Тексты и тон».
- Code Connect — нужен тариф Figma Organization / Enterprise (сейчас Pro); токенов прозрачности и состояний pressed / disabled / loading у кнопок пока нет.

## Как вносить изменения
Полный порядок и чек-лист PR — `CONTRIBUTING.md` в репозитории.
1. Изменение в Figma (компонент или переменная, под замком в issue «Координация») → запись в Changelog на странице.
2. Токены — в `tokens/tokens.json`, затем `npm run tokens` (CSS, Swift, Kotlin) и `npm run docs-tokens`. Компоненты — в коде + story «В флоу».
3. Строка в `src/docs/registry.ts` со статусом; решение, меняющее правило, — ADR в `design/adr/`.
4. Storybook публикуется на GitHub Pages автоматически после мержа.
