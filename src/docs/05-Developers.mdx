# Для разработчиков

Короткий указатель: всё подробное живёт на своих страницах и в файлах репозитория.

| Что нужно | Где |
|---|---|
| Запустить, подключить (web, iOS, Android), скачать токены и иконки | **Старт / Быстрый старт** |
| Общие хуки и примитивы доступности: `useControllableState`, `VisuallyHidden`, кольцо фокуса | **Старт / Для разработчиков / Примитивы** (`src/utils`) |
| Соответствие компонентов Figma и кода, статус зрелости | **Старт / Процессы / Figma ↔ код** (`src/docs/registry.ts`) |
| Нативные платформы | **Старт / Процессы / iOS и Android** (`native/ios`, `native/android`) |
| Выгрузки: токены, спрайт иконок, шрифты, архив | **Старт / Процессы / Ресурсы** |
| Каркасы экранов | **Templates** (`src/templates`) |
| Добавить или изменить компонент, чек-лист PR | `CONTRIBUTING.md` |
| Работа параллельно с другими сессиями и ботами | `TEAM.md` |

## Релизы

Версия — в `package.json`, семвер. Каждый PR, который меняет то, что получают приложения, добавляет запись `npx changeset`.
Релиз готовит человек: `npm run release:version` (версия и `CHANGELOG.md`), PR «Release vX.Y.Z», затем тег `vX.Y.Z` —
workflow `release.yml` создаёт GitHub Release с CHANGELOG и диффом токенов. Подробно — раздел «Релизы» в `README.md`
и `.changeset/README.md`.
