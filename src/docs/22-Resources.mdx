## Готово, если…

Компонент или экран считается готовым, когда выполнено всё:

1. В Figma он собран из компонентов DS 0.2, цвета и тексты привязаны к переменным и стилям (без «сырых» hex).
2. В Storybook есть история, свойства совпадают с Figma по имени и значениям; строка в реестре «Figma ↔ код».
3. Расхождение с экраном-эталоном по положению текстов — **не больше 2 px** (`npm run flow-diff`, сверка в Figma).
4. `npm run qa` — **0 ошибок** в светлой и тёмной теме на всех размерах экрана (320–430); спеки Figma в пределах 1 px.
5. `npm run contrast` — текст ≥ 4.5 : 1, иконки ≥ 3 : 1 в обеих темах.
6. Анимация — на токенах `--motion-*`, есть поведение при «уменьшить движение», описана хаптика для iOS и Android.
7. Токены совпадают в Figma (Light и Dark) и в `tokens.json`; iOS и Android сгенерированы (`npm run tokens`).
