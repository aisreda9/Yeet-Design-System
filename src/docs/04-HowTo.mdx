# Как пользоваться

## Дизайнерам
1. Собирайте экраны из компонентов страницы **Design System 0.2** в Figma — не отвязывайте инстансы.
2. Цвета — только из коллекции **Yeet DS 2.0**; проверяйте экран в режиме Dark.
3. Нужного варианта нет → сначала проверьте раздел «В флоу», потом предлагайте новый вариант компонента, а не локальную правку.
4. Называйте экраны `Раздел / Экран / Состояние`: `Wardrobe / Items / Empty`. Оверлеи — `… / Sheet / …`, `… / Dialog / …`, `… / Toast / …`.
5. Проектируйте экран во всех состояниях: Default / Populated, Empty, No Results, Focused, Filled, Loading.

## Разработчикам
Запуск, подключение (web, iOS, Android), ассеты, JSON и проверки — **Старт / Быстрый старт**. Правила токенов и слоёв там же.
Указатель по коду, примитивам и релизам — **Старт / Для разработчиков**.

## Карта меню

| Раздел | Что там |
|---|---|
| **Старт** | Быстрый старт, о проекте, принципы, атомарная система, эта страница |
| Старт / **Прототип** | Все экраны из Pages, связанные в кликабельное приложение: переходы, шторки, жесты |
| Старт / **Процессы** | Figma ↔ код (реестр и статусы), iOS и Android, Ресурсы (выгрузки и ссылки) |
| Старт / **Для разработчиков** | Указатель по коду и релизам, примитивы поведения и доступности (`src/utils`) |
| **Foundations** | Токены, бренд-палитры, типографика, отступы, иконки, скролл, вёрстка, анимации, тексты — правила без компонентов |
| **Atoms → Molecules → Organisms** | Компоненты по уровням: песочница, варианты, «В флоу» |
| **Templates** | Каркасы экранов без данных: `Screen`, `DetailsScreen`, `Prose` |
| **Pages** | Экраны флоу по одному, с реальными текстами и названиями как в Figma |

**Templates или Pages?** Шаблон — это раскладка: какие зоны есть у экрана (шапка, контент, низ, слои), что в них закреплено,
как они ведут себя при скролле. В историях Templates вместо контента — серые слоты-заглушки с подписями: видно устройство,
а не конкретный экран. Страница — это шаблон, заполненный организмами и реальными данными: `Pages / Экраны флоу / Wardrobe / Items / Populated` —
тот же `Screen`, но с настоящей шапкой, сеткой вещей и таб-баром. Меняется раскладка — правьте шаблон; меняется один экран — страницу.

## Чек-лист нового компонента
Полный порядок (Figma → реестр → код → «В флоу» → QA → эталоны) и чек-лист PR — `CONTRIBUTING.md` в репозитории.

- [ ] Есть в Figma с вариантами и описанием, привязан к токенам Yeet DS 2.0
- [ ] Реализован на своём атомарном уровне, использует только нижние уровни
- [ ] Story: Playground, все варианты, «В флоу» с реальными текстами экранов
- [ ] Проверен в светлой и тёмной теме
- [ ] Тексты гендерно-нейтральные
- [ ] Строка в `src/docs/registry.ts` со статусом (`alpha` / `beta` / `stable`) — по факту
- [ ] `npm run qa` без ошибок, эталоны скриншотов в том же PR
