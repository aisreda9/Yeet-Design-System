# Типографика

Пять стилей — и только они. Заголовки — **Roboto Slab**, всё остальное — **Inter**.

<TypeScale />

- Вес — ось вариативного шрифта: H1 — 380, Body — 460. Без вариативного шрифта — ближайший статический (Regular 400 / Medium 500).
- Вторичный текст — тот же стиль, цвет `--color-text-secondary`.
- Акцент внутри заголовка допустим: «Твои образы **на каждый день**» — вторая строка `--color-text-accent`.
- Без ручных размеров шрифта — только классы `.y-h1 … .y-caption` или `<Text variant>`.
