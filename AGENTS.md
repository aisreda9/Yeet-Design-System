# Правила для ИИ-агентов

Все агенты (Claude, Codex, Cursor, Copilot и другие боты) работают по одному протоколу: **`TEAM.md`**.
Краткая версия с командами — `CLAUDE.md`.

Перед началом работы: `npm run team` → взять issue → push и draft PR после первого коммита → работать только в своих зонах из `.github/team.json`.
