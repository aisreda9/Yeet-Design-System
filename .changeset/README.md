# Changesets

Каждый PR, который меняет то, что получают потребители (токены, компоненты React / SwiftUI / Compose, их API),
добавляет файл изменений:

```bash
npx changeset   # выбрать major / minor / patch и написать одну строку для CHANGELOG
```

Семвер для дизайн-системы:

- **major** — удалён или переименован токен, компонент, prop; значение токена изменилось так, что экраны поедут
  (другой отступ, другой цвет роли);
- **minor** — новый токен, компонент, prop, вариант; обратно совместимо;
- **patch** — исправление без изменения API: доступность, баг, уточнение значения в пределах той же роли.

Релиз делает человек — порядок в README, раздел «Релизы».
