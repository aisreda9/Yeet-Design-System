# 0002. Бренд-палитры — эксперимент, только web

- **Статус:** принято
- **Дата:** 2026-09-28
- **Где обсуждали:** `design/AUDIT.md` §3, решение 2; issue #13
- **Затрагивает:** tokens (`tokens.json` → `brand.*`), `scripts/check-contrast.mjs`, тулбар «Бренд» в Storybook

## Контекст

Кроме базовой синей темы в `tokens.json` есть несколько бренд-палитр. Часть их пар не проходит контраст AA, а перенос в iOS / Android удвоил бы работу платформ.

## Решение

Бренд-палитры — **эксперимент**: живут только в web и Storybook (тулбар «Бренд»), на iOS / Android не переносятся.
Команда выбирает одну; победитель становится основной палитрой (или остаётся вариантом), остальные удаляются из `tokens.json`.

## Последствия

- `npm run contrast`: провалы брендов — предупреждения, базовой темы — ошибки; `--brands=error` делает ошибками и бренды.
- Нативные генераторы (`npm run tokens`) бренды не выгружают.
- Когда палитру выберут — новая ADR, заменяющая эту.
