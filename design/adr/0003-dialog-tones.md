# 0003. Тоны диалога: default / destructive / danger

- **Статус:** принято
- **Дата:** 2026-09-28
- **Где обсуждали:** ветка `gallant-wozniak` (`design/AUDIT.md` §3)
- **Затрагивает:** organisms (`Dialog`), Figma `dialog` `962:3136`

## Контекст

В макетах подтверждения выглядят по-разному: очистка корзины и удаление образа — серая кнопка действия, удаление аккаунта — красная.
Один «destructive»-тон не описывал обе ситуации.

## Решение

`Tone` у `dialog` (в коде `tone`):

- **Default** — Tertiary + Primary;
- **Destructive** — необратимое, но восстановимое по смыслу действие: Tertiary слева + «Отмена» Primary (очистить корзину, удалить образ);
- **Danger** — удаление аккаунта: красная Destructive + «Отменить» Primary.

**Безопасное действие всегда синее и справа.** Вариант одной кнопки (уведомление) — Tertiary L на всю ширину, в коде `Dialog` без `cancel`.

## Последствия

- Описание и примеры — история `Organisms/Dialog` («В флоу»).
- Новые подтверждения выбирают тон по последствиям, а не по вкусу.
