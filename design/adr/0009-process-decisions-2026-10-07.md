- **Status:** accepted

## Context

The lead chats and the owner's HQ session are retired. Work now arrives from Linear and runs as fresh responder sessions.

## Decision

1. GitHub text (issues, PRs, comments, commits, docs) is English only.
2. Sync runs GitHub → Linear only. Answers from the owner are read in Linear and recorded in the GitHub issue in English.
3. Questions for the owner use the `Needs founder` label (`needs-owner` on GitHub) with a default the work continues on.
4. Agents merge their own PRs when the required checks are green; a failing check is fixed, never weakened or skipped.
5. Agent comments in Linear are posted as the Claude app or signed with the robot emoji.
6. Lead and HQ chats are retired; work arrives from Linear.
