# 0005. Эталоны скриншотов — в git, снимаются в закреплённом образе

- **Статус:** принято
- **Дата:** 2026-09-28
- **Где обсуждали:** фаза 1 `design/AUDIT.md`; `design/QA.md`
- **Затрагивает:** qa (`scripts/qa`, `qa/baseline`, `.github/workflows/qa.yml`)

## Контекст

Пиксели зависят от сборки Chromium, шрифтов и библиотек ОС. Эталоны, снятые на разных машинах, давали шум, а относительный порог 0,1 % пропускал сдвиг иконки на 2 px.

## Решение

Эталоны `qa/baseline/*.png` лежат в git и снимаются / сравниваются только в образе `mcr.microsoft.com/playwright` той же версии, что `playwright-core`
(тег и digest — `IMAGE` в `scripts/qa/lib.mjs`). `npm run qa` сам перезапускается в нём через Docker, локально и в CI одинаково.
Порог — любой пиксель сильнее pixelmatch 0,1 или другой размер снимка.

## Последствия

- Намеренное изменение вида = `npm run qa -- --update-baseline` и PNG в том же PR: визуальное ревью — это дифф PNG.
- Конфликт в `qa/baseline` — взять любую сторону и перегенерировать на смёрженной ветке.
- Без Docker локально скриншоты не сравниваются (в отчёте это видно); в CI без Docker — ошибка.
- Обновили `playwright-core` — меняется `IMAGE` и перегенерируются все эталоны. Подробно — `design/QA.md`.
