# 0006. Токены контраста (итерация QA 1)

- **Статус:** принято
- **Дата:** 2026-09-25
- **Где обсуждали:** `design/QA.md` → «Решено по контрасту»
- **Затрагивает:** tokens, Figma-коллекция «Yeet DS 2.0»

## Контекст

Первый прогон QA дал 78 предупреждений контраста: серый текст на `#F7F7F7`, белый на красном бейдже, синий в тёмной теме.

## Решение

- `text-secondary` → `#6E6E6E` (4,85 : 1 на белом, 4,53 : 1 на `#F7F7F7`).
- `danger` (заливка) → `#CC291B`: белый текст бейджа 5,4 : 1. `text-danger` в тёмной — `#FF6B5C`.
- Тёмная тема: `accent` → `#4B4BFF` (белый текст 5,6 : 1), `text-accent` → `#8A8AFF`.
- В Figma текст отделён от заливок: `ui-colors/blue-text`, `ui-colors/red-text`.

## Последствия

- `npm run contrast` проверяет все пары из `tokens.json`; таблица ключевых пар генерируется в `DESIGN.md` (`npm run docs-tokens`).
- Открыто: строки `list-item` 24 и кнопки S 32 — зона нажатия по [0001](./0001-tap-target-44-48.md).
