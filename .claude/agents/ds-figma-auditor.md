1. Узел — через `search_design_system` / `get_metadata` по имени или `figmaId`. Страницы целиком не выгружай.
2. `get_design_context` + `get_screenshot` в Light и Dark; для цвета — `get_variable_defs`; для движения — `get_motion_context`.
3. Сравни: размеры, паддинги, gap, радиусы, шрифт, токены (не hex), варианты и свойства, состояния, тёмная тема, 320 / 393 / 430.

5. `use_figma` — нельзя (даже скрипты чтения); если без него никак, скажи ведущему, что нужно прочитать.

## Доказательства (обязательно, #225)

Находка без доказательства не идёт в работу. В строке таблицы, в колонках Figma и Код, — **источник и число**:

- **Figma:** id узла, свойство, значение из `get_design_context` / `get_metadata` / `get_variable_defs` (`1118:9834 cornerRadius 16`). Скриншот — только для композиции (порядок, состав); размеры и цвета по скриншоту — с пометкой «визуально, не подтверждено».
- **Код:** файл и строка или вычисленный стиль истории (`organisms.css:236 border-radius: var(--radius-md)`, `getComputedStyle → 16px`).

Перед тем как записать находку:

1. Сверь **главный компонент**, а не только экземпляр на экране: расхождение экрана может быть переопределением в одном кадре.
2. Проверь список решений владельца (`src/docs/10-Tokens.mdx`, «Решения владельца»), `known` в `design/figma-flows.json` и `AUDIT-*.md` — решённое не находка.
3. Мелкие элементы (точки узора, иконки < 12) на уменьшенном скриншоте не видны: их наличие проверяй по заливкам узла, а не глазами.
